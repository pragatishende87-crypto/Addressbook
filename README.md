# Address Book Management System in C

## About the Project

This project is an Address Book Management System developed using the C programming language. It helps practise C programming, modular programming, and file handling.

## Technologies Used

- C Programming Language
- GCC Compiler
- Git and GitHub
- Ubuntu on WSL

## Project Files

- `main.c` — Main program
- `contact.c` and `contact.h` — Contact-related functionality
- `file.c` and `file.h` — File-handling functionality
- `contact.txt` — Contact data file

## How to Compile and Run

Compile the program:

```bash
gcc main.c contact.c file.c -o addressbook
```

Run the program:

```bash
./addressbook
```

## Learning Objectives

- Practise C programming
- Understand source and header files
- Learn file handling
- Use Git for version control
- Share code using GitHub
